# 0. Set up the tools

All the tools (Xschem, ngspice, Magic, netgen, KLayout) and the sky130 PDK come in **one Docker container** called IIC-OSIC-TOOLS.
Docker runs a small Linux computer inside your computer. You open its desktop in your web browser.

Pick your computer:

- [Mac](mac.html) (tested)
- [Windows](windows.html) (not tested yet)
- [Linux](linux.html) (not tested yet)

Needs about **20 GB** free disk space and 8 GB+ RAM.
